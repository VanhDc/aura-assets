# aura-assets

Static asset host for the weekly content-factory templates, served via the **jsDelivr** CDN.

Layout: `<template>/<...assets>`. Pin URLs to a git tag for immutable, cache-stable links:

```
https://cdn.jsdelivr.net/gh/VanhDc/aura-assets@genesis-v1/genesis/frames/f000.webp
https://cdn.jsdelivr.net/gh/VanhDc/aura-assets@genesis-v1/genesis/parallax/petal_rgba.png
```
